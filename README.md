# assets

Capturas y videos de prueba de los PRs de todos los repos de robert-flo.

- Ruta: `<repo>/pr-<número>/<archivo>` (por ejemplo `reel/pr-18/portada.png`).
- En el body del PR se embeben con `https://raw.githubusercontent.com/robert-flo/assets/main/<repo>/pr-<número>/<archivo>`.
- Solo se agregan archivos; no se borra ni se reescribe historia.
